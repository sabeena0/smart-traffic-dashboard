# Smart Traffic Safety Monitoring Dashboard

End-to-end project using NYC Motor Vehicle Collisions data:
pandas cleaning -> MongoDB -> aggregations and geospatial queries -> ML risk prediction -> Streamlit dashboard.

## Stack
Python, MongoDB (PyMongo), scikit-learn, Streamlit, Plotly, Folium

## Dataset
NYC Open Data - Motor Vehicle Collisions (Crashes). The CSV is not included in this repo.

## Status
Work in progress.
